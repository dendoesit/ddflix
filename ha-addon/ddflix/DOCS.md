# DDflix
Netflix local pentru televizoarele Samsung, cu web pe telefon. Filmele stau pe NAS: în Home Assistant, la *Settings → System → Storage*, montează share-ul NAS-ului cu numele `nas` și usage *Media*. Apare la `/media/nas`.
qBittorrent e inclus (Web UI pe portul 8081) și salvează în `download_dir`. Admin DDflix: http://IP-HA:8090
